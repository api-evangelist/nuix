Nuix is a provider of investigative analytics and intelligence software that delivers data privacy, fraud and investigations, and legal eDiscovery solutions (Nuix Neo, Nuix Workstation, Nuix Discover, Nuix Adaptive Security). Developers integrate through the Nuix Engine SDK documented at developer.nuix.com, the GraphQL-based Nuix Discover Connect API, and the self-hosted Nuix Adaptive Security REST API for endpoint collection, cases, jobs and targets.

**Areas:** Forensics · eDiscovery · Investigations · Compliance · Data Processing · Legal Tech · Intelligence

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Nuix: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
